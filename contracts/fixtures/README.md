# Fixtures

Generated by `contracts/fixtures/generate_fixtures.py`. Do not hand-edit the
JSON files; edit the generator and re-run it.

These fixtures are synthetic development data for FPT and KDH, produced so
the frontend and quantitative specialists can build against
`contracts/openapi.yaml` and `contracts/schemas/json/` with no backend
present (WP0 deliverable 4, P0 prompt). Every response envelope carries a
`provenance.warnings` entry saying so explicitly.

The only real, plan-verified number anywhere in these files is the FPT bar
for 2026-07-30, reproduced from the Section 10.1 example in
`vn_terminal_multi_ai_development_plan.md` v1.1 (O 65.2, H 67.2, L 64.8,
C 67.0, V 7,571,500). Every other price, volume, financial figure, and
security-master detail (company name, sector, listing date, and so on) is
synthetically generated or illustrative, not sourced from a real feed.
WP1/WP2/WP9 must replace these with real data; nothing here should be
quoted as a market fact.

| File | Matches schema | Notes |
|---|---|---|
| `bars_FPT.json`, `bars_KDH.json` | `bars_response.schema.json` | 520 daily bars each (>= 500 required). Final FPT bar is the verified Section 10.1 example. |
| `fundamentals_FPT.json`, `fundamentals_KDH.json` | `fundamentals_response.schema.json` | 12 quarters of revenue/net_income plus two derived metrics. One quarter has `publication_date: null` on purpose, to exercise the Section 17 degraded-mode path. |
| `strategy_evaluation_FPT.json`, `strategy_evaluation_KDH.json` | `strategy_evaluate_response.schema.json` | Reuses the literal `strategy_id`/field values from the Section 10.5 example. Not a real signal. |
| `ai_fact_bundle_FPT.json`, `ai_fact_bundle_KDH.json` | `ai_fact_bundle.schema.json` | Every number traces back to the corresponding bars/fundamentals/strategy-evaluation fixture above; nothing is invented independently, consistent with Section 18.1 ("AI may not... create missing price data"). |
| `strategy_definitions.json` | wraps a list of `strategy_definition.schema.json` | One entry, `minervini_trend_template`, with every rule field explicitly set to a `PLACEHOLDER` string. This is a schema-shape example only. Strategy specification is the user's work (Stream F / `docs/strategy_catalogue.md`), not an agent's; see `docs/decision_log.md`. |
| `security_master.json` | `symbols_response.schema.json` | FPT and KDH entries. `source: "fixture-placeholder"`; company details are illustrative. Not explicitly requested by the P0 prompt, added because `/api/symbols` and the security-master contract otherwise have no fixture. |

## Regenerating

```
cd vn-terminal
python contracts/fixtures/generate_fixtures.py
```

Requires the same environment as `contracts/build_openapi.py` (see
`pyproject.toml`). The script is deterministic (fixed random seeds) so
re-running it without code changes reproduces byte-identical output.
